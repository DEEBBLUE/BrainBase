Перестановкой называют [[Отображение#Биективно|биективное]] [[Отображение|отображение]] в себя на конечном множестве,обычно его называют $\Omega$ 
[[Множество]] все возможных перестановок на $\Omega$ обозначают как $S_n$,где $n=Card\Omega$ 
Пример перестановки.Пусть у нас есть конечное множество $\Omega=\{1,2,3,4\}$ и отображение $\sigma:\Omega\to\Omega$,которая сопоставляет все элементы $\Omega$ следующим образом $$\begin{pmatrix}1&2&3&4\\2&3&4&1\end{pmatrix}$$
## Свойства $S_n$ как множества
### Свойства группы
`1)Ассоциативность`.Тк $S_n$ - множество перестановок,то для его элементов верно [[Отображение#Композиция отображений#Теорема о композициях отображений. Композиция отображений подчиняется закону ассоциативности,то есть для отображений $$f A rightarrow B g B rightarrow C h C rightarrow D$$Выполняется следующее$$f(gh)=(fg)h$$|ассоциативное свойство отображений]].то есть для любых $\alpha,\beta,\gamma\in S_n$ справедливо равенство $$(\alpha\beta)\gamma=\alpha(\beta\gamma)$$
`2)Существование нейтатрального элемента`.Таким элементом является [[Отображение#Единичное отображение|единичное отображение]],которое обозначается как $e$.$\pi e=e\pi=\pi$
`3)Существование обратного элемента`.Для каждой перестановки $\pi\in S_n$ существует обратная $\pi^{-1}\in S_n$.$\pi\pi^{-1}=\pi^{-1}\pi=e$  
### card$S_n$=n!
Рассмотрим количество перестановок,которые сопоставляют 1-му элементу какой-то другой,таких будет n,теперь рассмотрим кол-во перестановок,которые сопоставляют 2-му элементу какой-то другой,их будет n-1,и так далее,перебрав все элементы,мы получим,что всего можно получить $n!$ перестановок

## Цикличность перестановок 
Нетрудно заметить ,что применяя перестановку $\sigma$ несколько раз самой к себе,то на 4-ое применение мы придём туда откуда начали,это есть выражение цикличность перестановок,иногда они называются циклами

В данном случае у нас цикл длины 4 и записывают в виде $\sigma=(1 \ 2 \ 3 \ 4)$ 
Ещё рассмотрим перестановку $\tau=\begin{pmatrix}1 & 2 & 3 & 4 \\ 4 & 3&2&1\end{pmatrix}$ ,и выглядеть она будет так ![[Снимок экрана_2026-07-19_20-02-19.png]]
То есть её можно представить в виде произведения двух циклов длинны 2 $\tau=(1 \ 4)(2 \ 3)$  
Теперь определим степень произвольной перестановки $\pi$ в $S_n$ следующим образом $$\pi^s=\begin{cases}\pi(\pi^{s-1})  \ \ \ \ \ \ \ \ \ \ \ \ \ если \ s>0\\
e \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ если \ s =0 \\
\pi^{-1}((\pi^{-1})^{s-1}) \ \ \  если \ s<0
\end{cases}$$
Отсюда вытекает,что $\pi^s\pi^t=\pi^{s+t}=\pi^t\pi^{s} \ \ (s,t\in\mathbb{Z})$ 
Теперь вспомним ,что все перестановки из $S_n$ это всё таки [[Отображение|отображения]] в себя на множестве $\Omega$ ,при этом $\Omega$ содержит конечное число элементов ,а значит для любой перестановки $\pi$ будет существовать такое число $q=q(\pi)$ такое ,что $\pi^q=e$ ,при этом множество в котором содержаться все степени $\pi$ обозначают как $\langle \pi \rangle =\{e,\pi,...,\pi^{q-1}\}$ ,само же число q называется порядком перестановки $\pi$.
## $\pi$-эквиваленты
Две точки $i,j\in\Omega$ называются $\pi$-эквивалентными,если $i=\pi^k(j)$
$i=\pi^0(i)$
$j=\pi^{-k}(i)$
$i=\pi^k(j),s=\pi^t(i)\Rightarrow s=\pi^{k+t}(j)$ 
Получается,что все условия [[Отношения#Отношение эквивалентости|эквивалентности]] выполнены,значит,в соответствии [[Отношения#Теорема.Множество Отношения Класс эквивалентности классов эквивалентности по отношению к $ textasciitilde$ задаёт Разбиение разбиение множества X,то есть X это объединение непересекающихся множетсв|свойством отношения эквивалентности]] можно разбить множество $\Omega$ $$\Omega=\Omega_1\cup\Omega_2\cup...\cup\Omega_p$$ множества на которые мы разбили на непересекающиеся множества ,которые ещё называют $\pi$-орбиталями.
Если $i\in\Omega_k$ ,тогда $\Omega_k$ состоит из i и из всех образов i,получаемых путём возведения в степень $\pi:i,\pi^(i),...,\pi^{l_k-1}$  ,где $l_k=|\Omega_k|$ - длина $\pi$-орбиты $\Omega_k$ .Очевидно,что:$$l_k\le q=Card\langle\pi\rangle, \ \ \ \ \pi^{l_k}=i$$ Причём $l_k$-это наименьшее число обладающее этим свойством.Положим $\pi_k=(i \ \pi(i) \ ... \ \pi^{l_k-1}(i))$ ,при этом все элементы из $\Omega\verb|\|\Omega_{k}$ она оставляет на месте,а для $\forall j\in\Omega_{k}$ $\pi(j)=\pi_{k}(j)$ ,тогда мы можем разбить перестановку $\pi$ на произведения перестановок $\pi_1,pi_2,...,pi_{p}$  $$\pi=\pi_1\pi_2...\pi_p$$
## Теорема о разложении перестановок в независимые циклы
Каждая перестановка $\pi\not=e$ в $S_n$ является произведением независимых циклов длинны $\geq 2$.Это разложение единственно с точностью до порядка следования цикла.
### Доказательство 
Пусть у нас есть перестановка $\pi\in S_n$ и она имеет два разложения $\pi=\pi_1\pi_2...\pi_q$ и $\pi=\alpha_1\alpha_2...\alpha_t$.Рассмотрим перестановки $\pi_k$ и $\alpha_g$ ,и рассмотрим элемент $i$ который не остаётся неизменным при действии $\pi$.Тогда $\pi_k(i)=\pi(i)=\alpha_g(i)$,так же выполняется $$\pi_k^e(i)=\pi^e(i)=\alpha_g^e(i)$$
Умножим всё на $\pi$,тогда $$\pi\pi_k^e(i)=\pi^{e+1}(i)=\pi\alpha_g^e(i)$$Или $$\pi_k^{e+1}(i)=\pi^{e+1}(i)=\alpha^{e+1}_g(i)$$
По индукции получается,что $k=0,1,2,3...$ или иными словами перестановка $\pi_k$ и $\alpha_g$ отличаются только индексом
## Транспозиции 
Транспозицией называется цикл длиной 2. Например $\tau=(1 \ 2)$
## Теорема о разложении перестановки в виде произведения транспозиции 
Всякую перестановку(необязательно единственным) образом можно представить в виде произведения транспозиций
### Доказательство 
Как уже доказывалось выше всякую перестановку можно разложить в виде произведения независимых циклов длинной $\geq 2$ ,но в свой очередь каждый из этих независимых циклов можно разложить в следующем виде $$(1 \ 2 ...\ l-1 \ l )=(1 \ l)(1 \ l-1)...(1 \ 3)(1 \ 2)$$
Кроме этого,транспозиции могут быть разными ,например $$(i_1 \ i_2 \ ... \ i_l)=(i_1 \ i_l)(i_1 \ i_{l-1})...(i_1 i_{2})$$  $$(i_1 \ i_2 \ ... \ i_l)=(i_2 \ i_1)(i_2 \ i_{l})...(i_2 i_{3})$$
но всегда их кол-во будет равным $l-1$ 
## Знак перестановки 
Пусть у нас есть перестановка $\pi\in S_n$ ,которая разложена в виде $$\pi=\tau_1\tau_2...\tau_k$$Тогда с ней ассоциировано число ,называемое знаком перестановки,$$\varepsilon_{\pi}=(-1)^k$$.Число $\varepsilon_{\pi}$ не зависит от того каким образом расположены транспозиции .Кроме этого $\varepsilon_{\alpha\beta}=\varepsilon_{\alpha}\varepsilon_{\beta}$
### Доказательство 
Пусть есть другое разложение на транспозиции для $\pi$ $$\pi=\tau'_1\tau'_2...\tau'_{k'}$$ при этом $k'\not=k$ ,кроме этого $k'+k$ должна быть нечётно,а иначе $\varepsilon_{k'}=\varepsilon_{k}$ 
Тогда $$\tau_1\tau_2...\tau_k=\tau'_1\tau'_2...\tau'_{k'}$$
Кроме этого $(\tau'_s)^2=e$ ,по этой причине будем последовательно умножать обе части на $\tau'_1\tau'_2...\tau'_k$ и в итоге получим $$\tau_1\tau_2...\tau_k\tau'_k\tau'_2...\tau'_1=e$$
Теперь всё свелось к следующему,нам нужно доказать,что если есть разложение $$e=\sigma_1\sigma_2...\sigma_m$$,То m обязательно должно быть чётно.Для это возьмём одно натуральных числа $1\le s\le n$ , которые входят в одну из транспозиция $\sigma_{p}=(s \ t)$ ,тогда для $\sigma_{p}$ имеется всего 4 возможных случая $$1)\sigma_{p-1}\sigma_{p}=(s \ t)(s \ t)=e$$$2) \sigma_{p-1}=(s \ r), \ \ r\not=s,t$$$\sigma_{p-1}\sigma_{p}=(s \ r)(s \ t) = (s \ t)(r \ t)$$
В таком случае мы просто сдвигаем $s$ влево
3)$\sigma_{p-1}=(t \ r)$,где $r \not =s,t$ $$\sigma_{p-1}\sigma_{p}=(t \ r)(s \ t)=(s \ r)(t \ r)$$
Мы снова просто сдвинули влево s
4)$\sigma_{p-1}=(q \ r)$,$\{q,r\}\cap\{s,t\}=\emptyset$ $$\sigma_{p-1}\sigma_{p}=(q \ r)(s \ t)=(s \ t)(q \ r)$$
Теперь применяя приёмы 2)-4) мы сместим s в самый первый ,если в процессе сдвигания влево мы не получим вариант 1,тогда у нас будет экстремальный случай,когда $\sigma=\sigma'_{1}\sigma'_{2}...\sigma'_{m}$ и $\sigma'_{1}=(s \ t')$ ,тогда $s=e(s)=\sigma_{1}(s)=t'\not=s$.Получается,что всякая перестановка $\sigma_{k}$ имеет 2 вхождения в $\sigma$ ,а значит $m$-чётное ,а значит число $\varepsilon_{k'}=\varepsilon_{k}$  
Теперь докажем,что $$\varepsilon_{\alpha\beta}=\varepsilon_{\alpha}\varepsilon_{\beta}$$ Это банальное свойство степеней,пусть у нас есть $\alpha=\alpha_1\alpha_2...\alpha_k$ и $\beta=\beta_1\beta_2...\beta_t=$,тогда $\alpha\beta=\alpha_1\alpha_2...\alpha_k\beta_1\beta_2...\beta_t=\alpha_1\alpha_2...\alpha_k\beta_{k+1}\beta_{k+2}...\beta_{k+t}$ отсюда видно,что $\varepsilon_{\alpha\beta}=(-1)^{k+t}=(-1)^k(-1)^t=\varepsilon_{\alpha}\varepsilon_{\beta}$ 
### Следствие
Пусть $\pi\in S_n$ перестановка разложенная в произведение независимых циклов длинной $l_1,l_2,...,l_m$.Тогда $$\varepsilon_{\pi}=(-1)^{\sum\limits_{k=1}^{m}(l_k-1)}$$
#### Доказательство 
Исходя и ранее доказанной теоремы $\varepsilon_{\pi}=\varepsilon_{\pi_1}\varepsilon_{\pi_2}...\varepsilon_{\pi_m}$,в то же время всякую перестановку [[Перестановки#Теорема о разложении перестановки в виде произведения транспозиции|можно разложить в виде произведения траспозиций]],при этом их количество будет равно $l_{k}-1$ ,тогда получим $$\varepsilon_{\pi}=(-1)^{l_1-1}(-1)^{l_2-1}...(-1)^{l_m-1}=\varepsilon_{\pi}=(-1)^{\sum\limits_{k=1}^{m}(l_k-1)}$$
## Чётность перестановки 
Перестановка называется чётной,если $\varepsilon_{\pi}=1$  и нечётной,если $\varepsilon_{\pi}=-1$
