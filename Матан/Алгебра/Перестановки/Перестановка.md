# Определение
## Перестановка
Перестановкой называют [[Отображение#Биективно|биективное]] [[Отображение|отображение]] в себя на конечном множестве,обычно его называют $\Omega$ 
[[Множество]] все возможных перестановок на $\Omega$ обозначают как $S_n$,где $n=Card\Omega$ 
Пример перестановки.Пусть у нас есть конечное множество $\Omega=\{1,2,3,4\}$ и отображение $\sigma:\Omega\to\Omega$,которая сопоставляет все элементы $\Omega$ следующим образом $$\begin{pmatrix}1&2&3&4\\2&3&4&1\end{pmatrix}$$
## Степень перестановки
Нетрудно заметить ,что применяя перестановку $\sigma$ несколько раз самой к себе,то на 4-ое применение мы придём туда откуда начали,это есть выражение цикличность перестановок,иногда они называются циклами 
![[Снимок экрана_2026-07-19_19-51-41.png|260]]
В данном случае у нас цикл длины 4 и записывают в виде $\sigma=(1 \ 2 \ 3 \ 4)$ 
Ещё рассмотрим перестановку $\tau=\begin{pmatrix}1 & 2 & 3 & 4 \\ 4 & 3&2&1\end{pmatrix}$ ,и выглядеть она будет так ![[Снимок экрана_2026-07-19_20-02-19.png]]
То есть её можно представить в виде произведения двух циклов длинны 2 $\tau=(1 \ 4)(2 \ 3)$  
Теперь определим степень произвольной перестановки $\pi$ в $S_n$ следующим образом $$\pi^s=\begin{cases}\pi(\pi^{s-1})  \ \ \ \ \ \ \ \ \ \ \ \ \ если \ s>0\\
e \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ если \ s =0 \\
\pi^{-1}((\pi^{-1})^{s-1}) \ \ \  если \ s<0
\end{cases}$$
Отсюда вытекает,что $\pi^s\pi^t=\pi^{s+t}=\pi^t\pi^{s} \ \ (s,t\in\mathbb{Z})$ 
## Порядок перестановки
Теперь вспомним ,что все перестановки из $S_n$ это всё таки [[Отображение|отображения]] в себя на множестве $\Omega$ ,при этом $\Omega$ содержит конечное число элементов ,а значит для любой перестановки $\pi$ будет существовать такое число $q=q(\pi)$ такое ,что $\pi^q=e$ ,при этом множество в котором содержаться все степени $\pi$ обозначают как $\langle \pi \rangle =\{e,\pi,...,\pi^{q-1}\}$ ,само же число q называется порядком перестановки $\pi$
## Транспозиции 
Транспозицией называется цикл длиной 2. Например $\tau=(1 \ 2)$
## Действие перестановки на [[Функция|функцию]]
Пусть $\pi\in S_n$ и f - функция от любых n аргументов. Полагаем $$(\pi\circ f)(x_1,x_2,...,x_n)=f(x_{\pi 1},x_{\pi 2},...,x_{\pi n})$$
Говорят,что функций $g = \pi\circ f$ получается действием перестановки $\pi$ на функцию $f$ 
# Теоремы
## Свойства $S_n$ как множества
### Свойства группы
`1)Ассоциативность`.Тк $S_n$ - [[Множество|множество]] перестановок,то для его элементов верно [[Отображение#Композиция отображений#Теорема о композициях отображений|ассоциативное свойство отображений]].то есть для любых $\alpha,\beta,\gamma\in S_n$ справедливо равенство $$(\alpha\beta)\gamma=\alpha(\beta\gamma)$$
`2)Существование нейтатрального элемента`.Таким элементом является [[Отображение#Единичное отображение|единичное отображение]],которое обозначается как $e$.$\pi e=e\pi=\pi$
`3)Существование обратного элемента`.Для каждой перестановки $\pi\in S_n$ существует обратная $\pi^{-1}\in S_n$.$\pi\pi^{-1}=\pi^{-1}\pi=e$  
### card$S_n$=n!
Рассмотрим количество перестановок,которые сопоставляют 1-му элементу какой-то другой,таких будет n,теперь рассмотрим кол-во перестановок,которые сопоставляют 2-му элементу какой-то другой,их будет n-1,и так далее,перебрав все элементы,мы получим,что всего можно получить $n!$ перестановок
## Теорема о разложении перестановок в независимые циклы
Каждая перестановка $\pi\not=e$ в $S_n$ является произведением независимых циклов длинны $\geq 2$.Это разложение единственно с точностью до порядка следования цикла.
### Доказательство 
Пусть у нас есть перестановка $\pi\in S_n$ и она имеет два разложения $\pi=\pi_1\pi_2...\pi_q$ и $\pi=\alpha_1\alpha_2...\alpha_t$.Рассмотрим перестановки $\pi_k$ и $\alpha_g$ ,и рассмотрим элемент $i$ который не остаётся неизменным при действии $\pi$.Тогда $\pi_k(i)=\pi(i)=\alpha_g(i)$,так же выполняется $$\pi_k^e(i)=\pi^e(i)=\alpha_g^e(i)$$
Умножим всё на $\pi$,тогда $$\pi\pi_k^e(i)=\pi^{e+1}(i)=\pi\alpha_g^e(i)$$Или $$\pi_k^{e+1}(i)=\pi^{e+1}(i)=\alpha^{e+1}_g(i)$$
По индукции получается,что $k=0,1,2,3...$ или иными словами перестановка $\pi_k$ и $\alpha_g$ отличаются только индексом
## Теорема о разложении перестановки в виде произведения транспозиции 
Всякую перестановку(необязательно единственным) образом можно представить в виде произведения транспозиций
### Доказательство 
Как уже доказывалось выше всякую перестановку можно разложить в виде произведения независимых циклов длинной $\geq 2$ ,но в свой очередь каждый из этих независимых циклов можно разложить в следующем виде $$(1 \ 2 ...\ l-1 \ l )=(1 \ l)(1 \ l-1)...(1 \ 3)(1 \ 2)$$
Кроме этого,транспозиции могут быть разными ,например $$(i_1 \ i_2 \ ... \ i_l)=(i_1 \ i_l)(i_1 \ i_{l-1})...(i_1 i_{2})$$  $$(i_1 \ i_2 \ ... \ i_l)=(i_2 \ i_1)(i_2 \ i_{l})...(i_2 i_{3})$$
но всегда их кол-во будет равным $l-1$ 
## Свойства действия перестановки на функцию
Пусть $\alpha,\beta$ любые перестановки из $S_n$. Тогда $$(\alpha\beta)\circ f=\alpha\circ(\beta\circ f)$$
### Доказательство 
$$(\alpha\circ(\beta\circ f))(x_1,x_2,...,x_n)=(\beta\circ f)(x_{\alpha 1},x_{\alpha 2},...,x_{\alpha n})$$
Переобозначим $x_{\alpha 1},x_{\alpha 2},...,x_{\alpha n}$ на $y_1,y_2,...,y_n$ ,кроме этого заметим ,что $y_{\beta i}=x_{\alpha(\beta_i)}$.Тогда $$(\alpha\circ(\beta\circ f))(x_1,x_2,...,x_n)=(\beta\circ f)(y_{ 1},y_{2},...,y_{n})=f(y_{\beta 1},y_{\beta 2},...,y_{\beta n})=f(x_{\alpha(\beta1)},x_{\alpha(\beta2)},...,x_{\alpha(\beta n)})$$
$$= f(x_{(\alpha\beta)1},x_{(\alpha\beta)2},...,x_{(\alpha\beta) n})=((\alpha\beta)\circ f)(x_1,x_2,...,x_n)$$
