# Аксиомы теории множеств
## 1.Аксиома объёмности.
Множетсва А и В равны тогда и только тогда,когда они имеют одни и те же элементы.
## 2.Аксиома выделения.
Любому множеству А и свойтсву P отвечает множетсво В,элементы которого суть те и только те элементы множества А,которые обладают свойством P
## 3.Аксиома объединения 
Для любого множества М множеств существует множетсво $\bigcup$ M,называемое объединением множетсва М,состоящее из тех и только тех элементов ,которые содержаться в элементах множетсва М
## 4.Аксиома пары.
Для любых множеств X,Y существует множество Z такое,что Х и Y являються его единственными членами
## 5.Аксиома множества подмножеств
Для любого множества Х существует множество $\mathcal{P}(X)$,состоящее из тех и только из тех элментов ,которые являются подмножествами множества X  
# Определения
## Множетсво
Множетсва нельзя определить,но тут будет описана наивная теория множеств,для которой множество S это совокупность объектов

## Мощность множетсва
Мощностью множетсва X называют такое число,обозначаемое $cardX$ ,равное количеству элементов во множетсва X
## Последователь множетсва
Последователем множества Х является множетсва $X^+$=$X\cup\{X\}$  .Это означает,что множетсво $X^+$ состоит из самого множетсва Х и множеств,которые содержат каждыей отдельный элемент Х.
## Открытое множество 
Открытым множеством называют такое множество Х,в котором каждый элемент $x\in X$ входит в X с некоторой $\varepsilon$-окрестностью.Более строго ,множество $X\subset\mathbb{R}^n$ называется открытым,если для каждого $x\in X$ $\exists\delta>0$,такое,что $O_{\delta}(x)\subset X$ ,где $O_{\delta}(x)$ - это открытый шар $$O_{\delta}(x):=\{a\in \mathbb{R}^n \ \ | \ \ d(a,x)<\delta\}$$
## Множество открытое в X
Пусть $X\subset \mathbb{R}^n$.Тогда множество $U\subset X$ называется открытыми в X,если $\forall u\in U$ будет существовать $O_{\varepsilon}(u)$ такой,что $O_{\varepsilon}(u)\cap X\subset U$
