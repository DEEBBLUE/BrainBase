# Определения 
Функции в матанализе это [[Отображение|отображения]],но я специально ввёл дополнительную заметку для них ,потому что в матанализе для функций существуют специфические категории,а именно 
## Финально постоянная функция 
Финально постоянной функцией при $E\ni x\to a$ будет называться функция ,которая принимает одинаковое значение в некоторой [[Окрестность#Проколотая окрестность|проколотой окрестности]] $\mathring{U}_{E}(a)$ точки a,[[Предельная точка|предельной]] для множества E.
## Ограниченная функция 
Функция называется ограниченной,ограниченной сверху,снизу,если существует такое число $C\in\mathbb{R}$,такое что для $\forall x\in E$ значение $|f(x)|<C$ ,тогда функция называется ограниченное,если $f(x)<C(f(x)>C)$,то ограниченной сверху(снизу) 
## Финально ограниченная функция
Если функция ограниченна только на какой-то проколотой окрестности $\mathring{U}_{E}(a)$.Или в терминах [[База фильтр|базы фильтра]] должен быть такой $B\in\mathcal{B}$,что $|f(B)|<M$ 
## Арифметические операции с функциями 
Если $f(x)$ и $g(x)$ две числовые функции имеющие общую область определения $E$,то их суммой,произведением и частным называются функции определённые на том же множестве следующими формулами: $$(f+g)(x)=f(x)+g(x)$$$$(f\cdot g)(x)=f(x)\cdot g(x)$$$$(\frac{f}{g})(x)=\frac{f(x)}{g(x)}, \ \ \ \ если \ \ g(x)\not=0 \ \ при x\in E$$ 

## Бесконечно малая
Бесконечной малой функцией при $E\ni x\to a$ называют такую функцию $\alpha:E\to\mathbb{R}$ ,что $\lim\limits_{E\ni x\to a}\alpha(x)=0$.Или если переписать через [[Предел по базе|предел по базе]] $\mathcal{B}$,то получим $$(\alpha(x)-\ бесконечно \ \ малая) \Leftrightarrow (\forall V(0)\ \exists B\in\mathcal{B} : \alpha(B)\subset V(0))$$
## Бесконечно большая
Функцию f называют бесконечно большой по базе $\mathcal{B}$ ,если [[Предел по базе|предел]] $\lim\limits_{\mathcal{B}}f(x)=\infty$
## Кососимметрические функции
Функция f от n аргументов называется кососимметричечкой,если для неё выполняется $$f(...,x_k,x_{k+1},...)=-f(...,x_{k+1},x_k,...)$$
(То есть если поменять местами два соседних аргумента,то знак функции меняется)
## Точка локального максимума(минимума)
Точка $x_0\in E\subset\mathbb{R}$ называется точкой локального максимума(минимума),а значение в ней - локальным максимумом(минимумом) функции $f:E\to\mathbb{R}$ ,если существует окрестность $U_{E}(x_0)$ такая,что в любой точке $x\in U_{E}(x_0)$ имеем $f(x)\le f(x_0)(соответственно,\ \ f(x)\geq f(x_0))$    
## Точка строгого локального максимума(минимума) 
Точка $x_0\in E\subset\mathbb{R}$ называется точкой строгого локального максимума(минимума),а значение в ней - строгим локальным максимумом(минимумом) функции $f:E\to\mathbb{R}$ ,если существует выколотая окрестность $\mathring{U}_{E}(x_0)$ такая,что в любой точке $x\in\mathring{U}_{E}(x_0)$ имеем $f(x)<f(x_0)$ (соответственно,$f(x)>f(x_0)$) 
## Точки локального экстремума 
Точки локального максимума и минимума называются точками экстремума,а значения функции в них - локальными экстремумами функции
## Точка внутреннего экстремума 
Точку $x_0\in E$ экстремума функции $f:E\to\mathbb{R}$ будем называть точкой внутреннего экстремума ,если она одновременно является [[Предельная точка|предельной точкой]] для множества $E_{-}=\{x\in E|x<x_0\}$ и для множества $E_{+}=\{x\in E|x>x_0\}$ 
## Выпуклая функция 
Функция $f:]a;b[\to\mathbb{R}$ определённая на интервале $]a;b[\subset\mathbb{R}$ называется выпуклой на нем,если для любых точeк $x_1,x_2\in]a;b[$ и любых чисел $\alpha_1\geq0,\alpha_2\geq0$ таких,что $\alpha_1+\alpha_2=1$ имеет место неравенство $$f(\alpha_1 x_1+\alpha_2 x_2)\le\alpha_1f(x_1)+\alpha_2f(x_2)$$ Если при $x_1\not=x_2$ и $\alpha_1\cdot\alpha_2\not=0$ это неравенство является строгим ,то функция называется строго выпуклой 
# Теоремы 
## Свойства кососимметрической функции
Если поменять местами любые два аргумента кососимметрической функции её знак сменится на противоположный 
#### Доказательство 
Докажем это по индукции.Пусть есть $i$-й и $j$-й  аргументы,$i<j$,которые мы хотим поменять местами,тогда проверим это утверждение для $l$-количество аргументов между ними $l=j-i-1$.Проверим это при $l=0$,тогда получим $0=j-i-1\Rightarrow j=i+1$ ,а это и есть определение кососимметрической функции.Пусть это верно для $j-i-1<l$,тогда $$f(...,x_i,x_{i+1},...,x_{j-1},x_j,...)=-f(...,x_{i+1},x_{i},...,x_{j-1},x_j,...)=$$$$f(...,x_{i+1},x_{j},...,x_{j-1},x_i,...)=-f(...,x_j,x_{i+1},...,x_{j-1},x_i,...)$$
## Условия внутреннего экстремума 
### Необходимое условие 
Для того чтобы точка $x_0$ была точкой экстремума функции $f:U(x_0)\to\mathbb{R}$ ,определённой в окрестности $U(x_0)$ этой точки,необходимо выполнение одного из двух условий: либо функция не дифференцируема в точке $x_0$,либо $f'(x_0)=0$ 
#### Доказательство 
Докажем,что если функция $f:U(x_0)\to\mathbb{R}$ в точке $x_0$ имеет производную,то $x_0$ - точка внутреннего экстремума.По [[Дифференциальное исчисление функции одной переменной#Теоремы#Лемма Ферма|лемме Ферма]] получим,что $f'(x_0)=0$,а значит $x_0$ - точка внутреннего экстремума
Теперь докажем,что если функция $f:U(x_0)\to\mathbb{R}$ не дифференцируема в точке $x_0$,то точка $x_0$ - точка внутреннего экстремума.Запишем определение функции дифференцируемой в точке $x_0$:$$f(x)-f(x_0)=A(x-x_0)+o(x-x_0),при \ \ x \to x_0$$
Пусть $f'(x_0)$-не существует,значит ,что какой бы не взяли $x\in U(x_0)$,то условие выполнено автоматически

### Достаточное условие 
Пусть $f:U(x_0)\to\mathbb{R}$ - функция ,определённая в окрестности  $U(x_0)$ точки $x_0$ ,[[Непрерывная функция в точке|непрерывная]] в самой этой точке и дифференцируемая в её проколотой окрестности $\mathring{U}(x_0)$.Пусть $\mathring{U}^{-}=\{x\in U(x_0)|x<x_0\}$ и  $\mathring{U}^{+}=\{x\in U(x_0)|x_0<x\}$.Тогда справедливы следующие утверждения:
$$1) \ (\forall x\in\mathring{U}^{-} (f'(x)<0)\land(\forall x\in\mathring{U}^{+}(f'(x)<0))\Rightarrow(x_0 - не \ \ точка \ \ внутреннего \ \ экстремума )$$
$$2) (\forall x\in\mathring{U}^{-} (f'(x)<0)\land(\forall x\in\mathring{U}^{+}(f'(x)>0))\Rightarrow(x_0 - точка \ \ строго \ \ локального \ \ минимума)$$
$$3) (\forall x\in\mathring{U}^{-} (f'(x)>0)\land(\forall x\in\mathring{U}^{+}(f'(x)<0))\Rightarrow(x_0 - точка \ \ строго \ \ локального \ \ макмимума)$$
$$4) \ (\forall x\in\mathring{U}^{-} (f'(x)>0)\land(\forall x\in\mathring{U}^{+}(f'(x)>0))\Rightarrow(x_0 - не \ \ точка \ \ внутреннего \ \ экстремума )$$
#### Доказательство 
Прямо следует из [[Дифференциальное исчисление функции одной переменной#Лемма Ферма#Лемма.Пусть функция $f(x)$ имеет конечную производную в точке $x_0$,тогда если производная $f'(x)>0[f'(x)<0]$,то при достаточно близких $x$ к $x_0$ справа,будет справедливо $f(x)>f(x_0)[f(x)<f(x_0)]$ ,а для $x$ близких слева наоборот $f(x)<f(x_0)[f(x)>f(x_0)]$| леммы в доказательстве теоремы Ферма]] и определения строгих локальных максимума и минимума
