Функции в матанализе это [[Отображение|отображения]],но я специально ввёл дополнительную заметку для них ,потому что в матанализе для функций существуют специфические категории,а именно 
### Финально постоянная функция 
Финально постоянной функцией при $E\ni x\to a$ будет называться функция ,которая принимает одинаковое значение в некоторой [[Окрестность#Проколотая окрестность|проколотой окрестности]] $\mathring{U}_{E}(a)$ точки a,[[Предельная точка|предельной]] для множества E.
### Ограниченная функция 
Функция называется ограниченной,ограниченной сверху,снизу,если существует такое число $C\in\mathbb{R}$,такое что для $\forall x\in E$ значение $|f(x)|<C$ ,тогда функция называется ограниченное,если $f(x)<C(f(x)>C)$,то ограниченной сверху(снизу) 
### Финально ограниченная функция
Если функция ограниченна только на какой-то проколотой окрестности $\mathring{U}_{E}(a)$ 
### Арифметические операции с функциями 
Если $f(x)$ и $g(x)$ две числовые функции имеющие общую область определения $E$,то их суммой,произведением и частным называются функции определённые на том же множестве следующими формулами: $$(f+g)(x)=f(x)+g(x)$$$$(f\cdot g)(x)=f(x)\cdot g(x)$$$$(\frac{f}{g})(x)=\frac{f(x)}{g(x)}, \ \ \ \ если \ \ g(x)\not=0 \ \ при x\in E$$ 

### Бесконечно малая
Бесконечной малой функцией при $E\ni x\to a$ называют такую функцию $\alpha:E\to\mathbb{R}$ ,что $\lim\limits_{E\ni x\to a}\alpha(x)=0$
