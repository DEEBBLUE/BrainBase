# Определения
## Определение 1
Точка $a\in E$ называется предельной точкой [[Множество|множества]] E если,в любой [[Окрестность#Проколотая окрестность|проколотой]] окрестности $\mathring{U}(a)$ бесконечное количество элементов множества $E$ 
## Определение 2
Так же эквивалентной этой формулировке является формулировка,что в любой [[Окрестность#Проколотая окрестность|проколотой]] окрестности $\mathring{U}(a)$ найдётся хотя бы 1 элемент из $E$
## Изолированная точка
Это точка,не являющаяся предельной для данного множества


# Теоремы
## Доказательство эквивалентности [[Предельная точка#Определения 1|определения один]] и [[Предельная точка#Определение 2|определения два]]
Докажем с начала,что первое эквивалентно второму,по первому определению в окрестности $\mathring{U}(a)$ лежит бесконечное количество элементов множества $E$ ,то есть это будет удовлетворять второму определению,тк по нему нужно ,чтобы был хотя бы 1,очевидно,что в бесконечном числе элементов есть этот минимально необходимый 1 элемент.
Тебе докажем,что из второго определения следует первое.Исходя из 2-го определения в любой окрестности $\mathring{U}^{\varepsilon}(a)$ лежит хотя бы 1 элемент из $E$,то есть есть такой $q_1\in E:a-\varepsilon < q_1 < a+\varepsilon$  ,теперь рассмотрим окрестность $\mathring{U}^{q_1}(a)$ внутри неё будет точка $q_2\in E:q_1-a<q_2<q_1+a$ потому что в [[Предельная точка#Определение 2|определении]] сказано,что в любой окрестности,есть хотя бы одна,мы можем проделать так бесконечное количество раз и получить множество $Q=\{q_1,q_2,...,q_n,...\}$ $Q \subset E$ .Все элементы множества Q лежат внутри $\mathring{U^\varepsilon}(a)$ ,то есть внутри этой окрестности лежит бесконечное количество элементов из E,что соответствует первому определению.
