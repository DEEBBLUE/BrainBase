## Определение по Коши
Будем говорить,что функция $f:E\to\mathbb{R}$ стремится к $A$,при $x$ стремящемся к $a$,если для $\forall\varepsilon>0$ существует число $\delta>0$ такое,что для любой точки $x\in E$ такой,что $|x-a|<\delta$ ,выполнено соотношение $|f(x)-A|<\varepsilon$ $$\lim\limits_{E\ni x\to a}f(x):=\forall\varepsilon>0\ \ \exists \delta>0 \ \ \forall x\in E(|x-a|<\delta\Rightarrow|f(a)-A|<\varepsilon)$$
Или же то же самое можно написать используя [[Окрестность|окрестности]] ,а именно [[Окрестность#Проколотая окрестность произвольного множества являющегося подмножеством $ mathbb{R}$|проколотую окрестность произвольного множества]] и [[Окрестность#Окрестность произвольного множества являющегося подмножеством $ mathbb{R}$|окрестность множества являющегося подмножеством ]]$\mathbb{R}$ $$\lim\limits_{E\ni x\to a}f(x):=\forall V_{\mathbb{R}}^{\varepsilon}(A)\ \ \exists\mathring{U}_E^{\delta}(a) \ \ ( \ f(\mathring{U}_E^{\delta}(a))\subset V_{E}^{\varepsilon}(A) \ )$$
## Определение по Гейне
Число А называется пределом функции $f(x)$ в точке $x_0$, если для любой последовательности аргументов $x_n$ ,cстремящейся к $x_0$,но не равной ей,соответствующая последовательность значений функции $f(x_n)$ стремится к А
## Доказательство эквивалентности определений по Гейне и по Коши
Соотношение $\lim\limits_{E\ni x\to a}f(x)=A$ имеет место тогда и только тогда,когда для любой последовательности $\{x_n\}$ точек $x_n\in E\verb|\|a$,сходящихся к a,[[Последовательность|последовательность]] $\{f(x_n)\}$ сходится к A.
### Доказательство 
Сначала из Коши докажем Гейне. Распишем определение Коши: запись $\lim\limits_{E\ni x\to a}f(x)=A$ означает,что для любой окрестности $V(A)$ будет существовать окрестность $\mathring{U}_{E}(a)$ точки а,такая что для любого $x\in\mathring{U}_{E}$ выполняется $f(x)\in V(A)$.Кроме этого возьмём любую последовательность $\{x_n\}$ стремящуюся к $a$,тогда по [[Предел последовательности#Опредление через окрестности|определению предела последовательности]] можно сказать,что будет $N$ такой,что $\forall n> N$ $x_n\in\mathring{U}_{E}(a)$,но исходя из определения Коши,мы получаем,что$f(x_n)\in V(A)$ или же $\lim\limits_{n\to\infty}f(x_n)=A$
Теперь из Коши будем доказывать Гейне. Пусть точка А не является пределом функции $f(x)$,при этом последовательность $\{x_n\}$ стремится к a,то есть будет существовать такая окрестность $V(A)$,что любая выколотая окрестность $\mathring{U}_{E}(a)$ содержит хотя бы 1 элемент $x\in\mathring{U}_{E}$ такой ,что $f(x)\not\in V(A)$ ,хотя сама последовательность стремится к a
