## Определение
Пусть $f:X\to\mathbb{R}$ - функция определённая на множестве X;$\mathcal{B}$ - [[База фильтр|база]] в X.Число $A\in\mathbb{R}$ называется пределом функции $f:X\to\mathbb{R}$ по базе $\mathcal{B}$ ,если для любой [[Окрестность#Окрестность произвольного множества являющегося подмножеством $ mathbb{R}$|окрестности]] $V(A)$ точки A найдётся элемент $B\in\mathcal{B}$ базы,образ которого лежит в $V(A)$ $$(\lim\limits_{\mathcal{B}}f(x)=A):=\forall V(A) \ \ \exists B\in\mathcal{B}(f(B)\subset V(A))$$
