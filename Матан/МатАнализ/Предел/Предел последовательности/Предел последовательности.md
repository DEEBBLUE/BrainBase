# Опредления 
Существует несколько опредлений,что такое предел [[Последовательность|последовательности]], я их приведу и докажу их эквивелентность 
## Определение Коши(на $\varepsilon -\delta$ языке)
Пределом последовательности X называют такое число А,что 
$$(\lim_{n\rightarrow\infty}x_n=A)\iff(\forall \varepsilon > 0 \ \exists N\in\mathbb{N}:\forall n\in\mathbb{N} \ \   n> N : |x_n-A|<\varepsilon)$$
## Опредление через окрестности
Пределом последовательности X называют такое число А,что $$(\lim_{n\rightarrow\infty}x_n=A)\iff(\forall V(A) \ \ \exists N\in\mathbb{N} \ \ \forall n > N (x_n\in V(A)))$$
## Доказательство эквивалентности [[Матан/МатАнализ/Предел/Предел последовательности/Предел последовательности#Определение Коши(на $ varepsilon - delta$ языке)|определения 1]] и [[Матан/МатАнализ/Предел/Предел последовательности/Предел последовательности#Опредление через окрестности|определения 2]] 
Сначала докажем,что из 1-го следует 2-е.То есть у нас есть последовательность Х,предел которой $$(\lim_{n\rightarrow\infty}x_n=A)\iff(\forall \varepsilon > 0 \ \exists N\in\mathbb{N}:\forall n\in\mathbb{N} \ \   n> N : |x_n-A|<\varepsilon)$$
Условием $\forall\varepsilon >0$ и $|x_n-A|<\varepsilon$ мы по сути задаём произвольную эпсилон окрестность точки А,а находя расстояние между A и $x_n$ мы пытаемся определить,лежит ли $x_n$ внутри этой $V(A)$.То есть всё выше сказанное можно записать в виде:$$(\lim_{n\rightarrow\infty}x_n=A)\iff(\forall V(A) \ \ \exists N\in \mathbb{N} \ \ \forall n >N \ \ x_n\in V(A))$$
Теперь покажем,что из 2-го следует 1-ое.Значит у нас есть последовательность Х и $$(\lim_{n\to\infty}x_n=A)\iff(\forall V(A) \ \ \exists N\in\mathbb{N} \ \ \forall n>N \ \ x_n\in V(A))$$
По опредлению $V(A)=\{x: A-\varepsilon < x < A+\varepsilon\} \Rightarrow \{x:|A-x|<\varepsilon\}$ 
## Опредление последовательность стремящейся к бесконечности 
Будем говорить ,что [[Последовательность|последовательность]] $\{x_n\}$ стремиться к бесконечности ,если для любого числа $c\in\mathbb{R}$ всегда найдется такой номер $N\in\mathbb{N}$,что для всех номеров $n>N(n\in\mathbb{N})$ выполняется $|x_n|>c$
На языке кванторов$$\{x_n\}\to\infty:=\forall c\in\mathbb{R} \ \ \exists N\in\mathbb{N}:\forall n>N (|x_n|>c)  $$
Аналогично вводятся понятия для $+\infty$ и $-\infty$$$\{x_n\}\to-\infty:=\forall c\in\mathbb{R} \ \ \exists N\in\mathbb{N}:\forall n>N (x_n<c)$$$$\{x_n\}\to+\infty:=\forall c\in\mathbb{R} \ \ \exists N\in\mathbb{N}:\forall n>N (x_n>c)$$
## Нижний и верхний предел 
### Нижний предел
Нижним называется предел $\lim\limits_{k\to\infty}\inf\limits_{k\geq n}x_k$ ,где $\inf\limits_{k\geq n}x_k$ это такое число a,что $inf_{k \geq n}x_k = a < x_k$ .Обозначается,как $\underline{\lim}\limits_{k\to\infty}x_k$ 
### Верхний предел 
Верхний предел вводится по аналогии,$\overline{\lim\limits_{k\to\infty}} x_k=\lim\limits_{k\to\infty}\sup\limits_{k\geq n}x_k$ 
## Частичный предел последовательности 
Частичным пределом последовательности называют число (или символы $-\infty$ и $+\infty$) если в этой последовательности есть подпоследовательность,стремящаяся к этому числу.
Последовательность имеет предел,только тогда ,когда все её подпоследовательности сходятся к одному и тому же числу.
