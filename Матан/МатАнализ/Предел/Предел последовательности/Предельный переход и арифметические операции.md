## Теорема 1.Если есть две [[Последовательность|последовательности]] $\{x_n\}$ $\{y_n\}$ ,таких что $\lim_{n\to\infty} \{x_n\}=A$ и $\lim_{n\to\infty} \{y_n\}=B$,тогда $\lim_{n\to\infty} (x_n+y_n)=A+B$ 
### Доказательство
По [[Предел последовательности#Определение Коши(на $ varepsilon - delta$ языке)|определению предела]] для каждой их этих последовательностей найдём $N_1,N_2\in\mathbb{N}$,такие ,что для $\frac{\varepsilon}{2}$ и любых $q>N_1$ и $p>N_2$ будет выполнено $|A-x_q|<\frac{\varepsilon}{2}$ и $|B-y_p|<\frac{\varepsilon}{2}$.Тогда положим $N=max\{N_1,N_2\}$ ,тогда $\forall \ n > N$  будет одновременно выполнено $|A-x_n|<\frac{\varepsilon}{2}$ и $|B-y_n|<\frac{\varepsilon}{2}$.Теперь просто сложим эти два неравенства,тогда получим$$|A-x_n|+|B-y_n|<\varepsilon$$
Теперь посмотрим на неравенство треугольника $$|a+b|\le|a|+|b|$$
Пременим его ,и получим $$|A-x_n+B-y_n|<\varepsilon$$
И сгрупировав,получим$$|(A+B)-(x_n+y_n)|<\varepsilon$$
А это не что иное,как опредление предела для последовательности $\{x_n+y_n\}$.То есть $$\lim_{n\to\infty}(x_n+y_n)=A+B$$


## Теорема 2.Если есть две [[Последовательность|последовательности]] $\{x_n\}$ $\{y_n\}$ ,таких что $\lim_{n\to\infty} \{x_n\}=A$ и $\lim_{n\to\infty} \{y_n\}=B$,тогда $\lim_{n\to\infty} (x_n*y_n)=A*B$
### Доказательство 
Нам нужно доказать ,что $|(A*B)-(x_n*y_n)|<\varepsilon$ .
Распишем $|(A*B)-(x_n*y_n)|$ через [[Погрешность#Абсолютная пограшность произведния|абсолютную погрешность произведения]] 
$$|(A*B)-(x_n*y_n)|\le |x_n|*\Delta(y_n)+|y_n|*\Delta(x_n)+\Delta(y_n)*\Delta(x_n)$$
Теперь мы оценили наше неравнество,как сумму 3х произведений ,каждое из которых должно быть меньше $\frac{\varepsilon}{3}$.Для этого найдём N' и N'',такие что :
$$\forall n > N' : \Delta(x_n)<min\{1,\frac{\varepsilon}{3(|B|+1)}\}$$
$$\forall n > N'' : \Delta(y_n)<min\{1,\frac{\varepsilon}{3(|A|+1)}\}$$
Теперь пусть $N=max\{N',N''\}$ ,тогда получим,что для $\forall n>N$
$$|x_n|<|A|+\Delta(x_n)<|A|+1 \ \ (тк\ \  \Delta(x_n)< 1)$$
$$|y_n|<|B|+\Delta (y_n)<|B|+1$$
Теперь оценим каждое слагаемое
$$|x_n|*\Delta(y_n)<(|A|+1)*\frac{\varepsilon}{3(|A|+1)}=\frac{\varepsilon}{3}$$
$$|y_n|*\Delta(x_n)<(|B|+1)*\frac{\varepsilon}{3(|B|+1)}=\frac{\varepsilon}{3}$$
$$\Delta(x_n)*\Delta(y_n)<min\{1,\frac{\varepsilon}{3}\}*min\{1,\frac{\varepsilon}{3}\}<\frac{\varepsilon}{3} \ \ (тк  \ |B|+1 \ (или \ |A|+1) \ \ > \ 0,то \ \ \frac{\varepsilon}{3(|B|+1)}<\frac{\varepsilon}{3})$$
И получается,что $$|x_n|*\Delta(y_n)+|y_n|*\Delta(x_n)+\Delta(y_n)*\Delta(x_n)<\varepsilon$$ Что и требовалось доказать
