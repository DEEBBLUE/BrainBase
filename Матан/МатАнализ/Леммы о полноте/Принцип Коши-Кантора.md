
# Определения
## Последовательность вложенных множетсв 
Пусть $X_1,X_2,...,X_n,...$ - это [[Последовательность|последовательность]] каких-то множетсв,таких что $$X_1\supset X_2 \supset X_3 \supset \ \ ...\ \ \supset X_n \supset \ \ ...$$
(то есть $\forall n\in\mathbb{B}$ выполнено $X_n\supset X_{n+1}$).Тогда этим множетсва называются *последовательностью вложенных множеств* 
# Принцип Коши-Кантора
Для любой [[Принцип Коши-Кантора#Последовательность вложенных множетсв|последовательность вложенных отрезков]] $I_1 \supset I_2 \supset ... \supset I_n \supset ...$   существует точка $c\in\mathbb{R}$ такая ,что она принадлежит всем отразкам одновременно.
Более того,если для любого $\varepsilon > 0$ в последовательности можно найти $I_k$ такой ,что $|I_k|<\varepsilon$ ,то такая точка $c$ единственная.
#### Доказательство 
Выделим из этих отрезков два упорядоченных множетсва $A=\{a_n|n\in\mathbb{N}\}$ левых концов отрезков и $B=\{b_n|n\in\mathbb{N}\}$ правых концов отрезка.Проверим выполяется ли для этих множетсв [[Аксиома полноты|аксиома полноты]].Во-первых,эти множества $A,B\subset\mathbb{R}$ ,во-вторых,$\forall a\in A$ и для $\forall b\in B$ выполнено $a\le b$ (что оевидно в силу того факта,что левый конец всегда меньше правого).Значит для этих множетсв выпоняется аксиома полноты и значит,что существует $c\in\mathbb{R}$ ,такой что $a\le c\le b$.
Теперь пусть две такие точки $c_1,c_2\in\mathbb{R}$ они различны(иначе просто не было бы смысла от этой теоремы) ,пусть $c_1<c_2$ ,тогда $0<c_2-c_1<b_n-a_n=|I_n|(1)$ ,тогда если будет сущетсвовать $I_k$ такой ,что $|I_k|<|I_n|$ то утверждение 1 будет неверным,что противоречит изначальному условию.
