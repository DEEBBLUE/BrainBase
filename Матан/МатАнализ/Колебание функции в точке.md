# Определения 
## Колебание функции в точке
Колебанием функции $f:E\to\mathbb{R}$ в точке $a\in E$ называется величина равная $$\omega(f;a)=\lim\limits_{\delta\to+0}\omega(f;U^{\delta}_{E}(a))$$ где $\omega(f;U^{\delta}_{E}(a))$ - это [[Колебание функции на множетсве|колебание]] на [[Множество|множестве]] являющимся $\delta$-[[Окрестность#Окрестность произвольного множества являющегося подмножеством $ mathbb{R}$|окрестностью]] точки $a\in E$ 
# Теоремы
## Существование значения $\omega(f;a)$ 
Величина $\omega(f;U^{\delta}_{E}(a))$ неубывающая функции.Потому что колебания на подмножестве не превышают колебания на множестве,значит для $\delta_2<\delta_1$ выполнено,что $\omega(f;U^{\delta_2}_{E}(a)\le \omega(f;U^{\delta_1}_{E}(a))$.Кроме этого по определению  [[Колебание функции на множетсве|колебания на множестве]] получаем,что величина $\omega(f;U^{\delta}_{E}(a))$ неотрицательна.А значит [[Критерии существования предела последовательности#Теорема Виерштарасса|по теореме Виерштрасса]] получаем,что предел $\lim\limits_{\delta\to+0}\omega(f;U^{\delta}_{E})$ существует.
