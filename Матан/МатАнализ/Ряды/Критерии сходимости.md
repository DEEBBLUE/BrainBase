# Критерий Коши
Исходя из определения [[Ряд#Частичная сумма ряда|частичной суммы ряда]] видно,что если сходится последовательность $\{s_n\}$ частичных сумм,то и ряд сходится,тогда к этой поселдовательности можно применить [[Критерии существования предела последовательности#Критерий Коши|критерий Коши для последовательностей]] и получить,что ряд $\sum\limits_{k=1}^{\infty}a_n$ сходится,если для любого $\varepsilon>0$ найдётся $N\in\mathbb{N}$ ,такое ,что для любых $n\geq m>N$ выполняется $|\sum\limits_{k=m}^{n}a_k|<\varepsilon$ 
## Следствие 1
Если заменить какое-то конечное число членов ряда,то если изнаальный ряд сходился,то и изменённый тоже будет сходится,если же ряд расходился,то и изменённый тоже будет расходтся
### Доказательство
Пусть есть ряд $\sum\limits_{n=1}^{\infty}a_n$ заменим в нём первые k членов случайными,теперь проверим критерий Коши для этого ряда,мы можем брать $\forall\varepsilon>0$ ,поэтому будет брать $\varepsilon$ такие,что $N>k$ ,тогда в силу того ,что k - это конечное число,тогда получим,что число $\varepsilon$ которые мы "откинули" тоже конечно,а вот $\varepsilon$ ,которые мы можем брать попреженму бесконечное число
## Следствие 2
Необходимым условием сходимости ряда $\sum\limits_{n=1}^{\infty}a_n$ является условие,что при $n\to\infty$ $a_n\to 0$ 
### Доказательство
$a_n=s_n-s_{n-1}$ ,тогда $\lim\limits_{n\to\infty}a_n=\lim\limits_{n\to\infty}(s_n-s_{n-1})=\lim\limits_{n\to\infty}s_n-\lim\limits_{n\to\infty}s_{n-1}=s-s=0$(s-это сумма $\sum\limits_{n=1}^{\infty}a_n$)

# Критерий сходимости ряда с неотрицательными членами 
Ряд $\sum{a_n}$,где $|a_n|\geq 0$ сходится ,если последовательность частичных сумм ограниченна сверху
### Доказательство
Это следует из [[Критерии существования предела последовательности#Теорема Виерштарасса|теоремы Виерштрасса]],осталось только проверить,что последовательность частичных сумм ряда с неотрицательными членами монотонно не убывающая,это очевидно,тк $s_n\le s_{n+1}$ ,значит условия теоремы Виерштрасса выполнены 
# Критерий сравения(Признак сравения)
Если есть два ряда $\sum a_n$ и $\sum b_n$ с неотрицатеьными членами.Если существует такой номер $N\in\mathbb{N}$ ,такой ,что для любого $n>N$ выполено $a_n\le b_n$,тогда если ряд $\sum b_n$ сходится,то и $\sum a_n$,а если $\sum a_n$ расходится,то и $\sum b_n$ тоже расходится
### Доказательство 
Тк конечное число членов не влияют на результат суммы ряда,то сразу будем считать ,что для $\forall n\in\mathbb{N}$ выполнено $a_n\le b_n$,тогда $A_n\le B_n \le B$,а значит,$A_n$ ограничена и в силу [[Критерии сходимости#Критерий сходимости ряда с неотрицательными членами|критерия сходимости для ряда с неотричетельынми членами]] получаем,что и ряд $\sum a_n$ сходится.Если же $\sum b_n$ расходится,то и $\sum a_n$ тоже расходится,тк  [[Критерии сходимости#Критерий сходимости ряда с неотрицательными членами|критерий сходимости для ряда с неотричетельынми членами]] не выполнен
## Следствие 1 (мажоротарный признак Вийерштрасса абсолютной сходимости)
Пусть $\sum a_n$ $\sum b_n$ - два ряда с неотрицательными членами.Пусть $\exists N\in\mathbb{N}$ ,такой,что $\forall n>N$ $|a_n|<b_n$,тогда если сходится ряд $\sum b_n$,то ряд $\sum a_n$ сходится абсолютно
Тут даже доказывать нечего,мы просто применили признак сравнения 
## Следствие 2(признак Коши)
Если есть [[Ряд|ряд]] $\sum\limits_{n=1}^{\infty}a_n$ и существует [[Предел последовательности#Верхний предел|верхний предел]] $\alpha=\overline\lim\limits_{n\to\infty}\sqrt[n]{|a_n|}$. Тогда спреведливо следующее:
$a) \ \ Если \ \ \alpha < 1 \ ,то \ \ ряд \sum\limits_{n=1}^{\infty}a_n \ \ сходится \ \ абсолютно$ 
$b)\ \ Если \ \ \alpha > 1 \ ,то \ \ ряд \sum\limits_{n=1}^{\infty}a_n \ \ расходится$
$c) \ \ Если \ \ \alpha = 1 \ ,то \ \ ничего \ \ нельзя \ \ сказать \ \ о \ \ том \ \ сходится \\ ли \\ ряд \ \ или \ \  расходится$
### Доказательство 
а)$Если \ \ \alpha < 1$.По [[Предел последовательности#Верхний предел|опредлению верхнего предела]] найдём число q, $\alpha<q<1$,такое ,что начиная с кого-то $N\in\mathbb{N}$,для любого $n>N$ выполнялось,что $\sqrt[n]|a_n|<q$,тогда $|a_n|<q^n$ ,теперь найдём сумму ряда $\sum\limits_{n=1}^{\infty}q^n$,тк $|q|<1$,то ряд сходится,тогда воспользовавшись [[Критерии сходимости#Критерий сравения(Признак сравения)#Следствие 1 (мажоротарный признак Вийерштрасса абсолютной сходимости)|признаком Вейерштрасса]] ,получим,что исходный ряд сходится абсолютно
b)$Если \ \ \alpha > 1$. Тк $\alpha$ - это частичный предел последовательности,то в последовательности $\{a_n\}$ ,будет подпоследовательность $\{a_{n_k}\}$,такая,что $\lim\limits_{k\to\infty}a_{n_k}=\alpha$ и тк $\alpha > 1$,то [[Критерии сходимости#Критерий Коши#Следствие 2|второе следствие критерия Коши]] не будет выполнено,а значит ряд - расходтся
c)$Если \ \ \alpha = 1$.Просто видно из прктики.Возьмём два ряда $\sum\limits_{n=1}^{\infty}\frac{1}{n}$ и $\sum\limits_{n=1}^{\infty}\frac{1}{n^2}$.Первый ряд,называемый гормоническим,расходится,тк для него не выполнен [[Критерии сходимости#Критерий Коши|критерий Коши]].Второй ряд, сходится,тк для него выполнен [[Критерии сходимости#Критерий сравения(Признак сравения)|признак сравнения]],но при этом $\overline\lim\limits_{n\to\infty}\sqrt[n]{|\frac{1}{n}|}=\overline\lim\limits_{n\to\infty}\sqrt[n]{|\frac{1}{n^2}|}=1$
## Следствие 3(Признак Даламбера)
Пусть для ряда $\sum\limits_{n=1}^{\infty}a_n$ существует предел $\lim\limits_{n\to\infty}|\frac{a_{n+1}}{a_n}|=1$,тогда спреведливы следующие утверждения:
$a) \ \ Если \ \ \alpha < 1 \ ,то \ \ ряд \sum\limits_{n=1}^{\infty}a_n \ \ сходится \ \ абсолютно$ 
$b)\ \ Если \ \ \alpha > 1 \ ,то \ \ ряд \sum\limits_{n=1}^{\infty}a_n \ \ расходится$
$c) \ \ Если \ \ \alpha = 1 \ ,то \ \ ничего \ \ нельзя \ \ сказать \ \ о \ \ том \ \ сходится \\ ли \\ ряд \ \ или \ \  расходится$ 
### Доказательство
а)$Если \ \ \alpha < 1$.Тогда возьмём q $\alpha<q<1$,тогда пользуясь [[Предел последовательности#Определение Коши(на $ varepsilon - delta$ языке)|определением предела последовательности]] возьмём произвольное $\varepsilon < 0$,тогда найдём $N\in\mathbb{N}:\forall n>N:$$|\alpha-b_n|=|b_n-\alpha|<\varepsilon \Rightarrow |b_n|< |\alpha|+\varepsilon(b_n=|\frac{a_{n+1}}{a_n}|)$.Тк конечное число членов ряда не влияют на соходомсть,то будем считать только члены с номерами n,такими,что $|b_n|<\alpha+\varepsilon=q<1$ ,тогда для каждого члена ряда можно записать,что $|b_n|=|\frac{a_{n+1}}{a_n}|<q$ ,тогда заметим,что $$|\frac{a_{n+1}}{a_n}|*|\frac{a_n}{a_{n*1}}|*...*|\frac{a_2}{a_1}|=|\frac{a_{n+1}}{a_1}|<q^n$$
Тогда $$|a_{n+1}|<|a_1|*q^n$$
А ряд $\sum\limits_{n=1}^{\infty}|a_1|*q^n$ сходится ( и равен $\frac{|a_1|}{1-q}$) ,значит по [[Критерии сходимости#Критерий сравения(Признак сравения)#Следствие 1 (мажоротарный признак Вийерштрасса абсолютной сходимости)|первому следствия признака сравнения]] ряд $\sum\limits_{n=1}^{\infty}a_n$ - сходится абсолютно.
b)$Если \ \ \alpha > 1$. Тогда начиная с какого-то N $|\frac{a_{n+1}}{a_n}|>1$,тогда $|a_{n+1}|>|a_n|$,или ,что тоже самое $a_n \not\to 0$ ,значит [[Критерии сходимости#Критерий Коши#Следствие 2|второе следствие критерия Коши]] не выполнено ,а значит ряд расходится
с)$Если \ \ \alpha = 1$.Тот же самый пример,что и в [[Критерии сходимости#Критерий сравения(Признак сравения)#Следствие 2(признак Коши)|признаке Коши]]

# Признак сходимости ряда,члены которого образуют [[Критерии существования предела последовательности#Определения монотонных последовательностей#Невозрастающая последовательность|монотонно невозрастающую последовательнось]]  
Если для членов ряда $\sum\limits_{n=1}^{\infty}a_n$ верно соотношение $a_1\geq a_{1} \geq ...\geq 0$,то изначальный ряд сходится,если сходится ряд $\sum\limits_{л=1}^{\infty}2^k*a_{2^k}$  
### Доказательство 
для всех членов ряда $\sum\limits_{n=1}^{\infty}a_n$ справедливо следующее $$a_2\le a_2 \le a_1$$$$2a_4\le a_3 +a_4 \le 2a_2$$$$4a_8\le a_5 + a_6+a_8+a_8\le 4a_4$$
$$...$$Просуммировав все эти неравенства получим$$A_{2^{n+1}}-a_1\le S_n$$ Воспользуемся [[Критерии сходимости#Критерий сравения(Признак сравения)|признаком сравнения]] и получим искомое утверждение
