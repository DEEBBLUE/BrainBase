# Определения 
## Функция непрерывная в точке 
Пусть $f(x)$ - вещественнозначная [[Функция#Определения|функция]] определённая в некоторой  [[Окрестность#Окрестность|окрестности]] точки $a\in\mathbb{R}$.Тогда говорят,что функция $f$ непрерывна ,если для любой окрестности $V(f(a))$ найдётся такая окрестность точки $a$,что $f(U(a))\subset V(f(a))$.Полная формальная запись и ещё несколько её вариантов: $$(f(x) -непрерывна \ \ в \ \ точке \ \ a):=(\forall V(f(a)) \ \  \exists U(a) \ \ [f(U(a))\subset V(f(a))] \ ),$$$$\forall\varepsilon>0\ \ \exists U(a) \ \ \forall x\in U(a) \ (|f(a)-f(x)|<\varepsilon),$$$$\forall\varepsilon >0\ \ \exists\delta>0 \ \ \forall x\in\mathbb{R} (|x-a|<\delta \Rightarrow |f(x)-f(a)<\varepsilon|)$$

 (Этим определением мы хотим записать,что функция непрерывна в точке,если по мере приближения аргумента к этой точке значение функции стремится к значению функции в этой точке,кроме этого мы по сути записали [[Предел функции#Определение по Коши|определения предела функции]] такого вида $\lim\limits_{x\to a}f(x)=f(a)$.Из этого факта и следует,что все формулировки эквивалентны друг другу,потому что это разные записи предела,но это определение предела,только если $a\in\mathbb{R}$).Рассмотрим общее определение непрерывности в точки,единственная отличие состоит в том,что теперь $f:\mathbb{R}\to\mathbb{R}$,а $f:E\to\mathbb{R}$,где $E\subset\mathbb{R}$ ,а значит мы будем рассматривать [[Окрестность#Окрестность произвольного множества являющегося подмножеством $ mathbb{R}$|окрестность произвольного множества]] из $\mathbb{R}$,а значит определение перепишется в виде $$(f(x) -непрерывна \ \ в \ \ точке \ \ a):=(\forall V(f(a)) \ \  \exists U_{E}(a) \ \ [f(U(a))\subset V(f(a))] \ ),$$
 Аналогично перепишутся и эквивалентные определения(а в случае с пределом,но будет выглядеть более канонично $\lim\limits_{E\ni x\to a}f(x)=f(a)$)
# Теоремы
## Свойства непрерывной функции в точке 
### Случаи для точки a 
Рассмотрим несколько случаев относительно точки $a$:
1) Точка $a$  [[Предельная точка#Изолированная точка|изолированная]] точка во [[Множество|множестве]] E
2) Точка $a$  [[Предельная точка|предельная]]  для множества E.Тогда $$(f \ \ нерперывна \ \ в \ \ точке \ \ a)\Leftrightarrow(\lim\limits_{E\ni x\to a}f(x)=f(a))$$
#### Доказательство 
Рассмотрим первый случай.Если точка $a$ [[Предельная точка#Изолированная точка|изолированная]],то найдётся окрестность $U_{E}(a)=a$,тогда ,по определению непрерывности получим,что $f(U(a))=f(a)\in V(f(a))$ ,для любой $V(f(a))$ 
Рассмотрим второй случай.Если точка $a$ [[Предельная точка|предельная точка]] на множестве E,тогда задана база $E\ni x\to a$ ,а значит это просто определение функции.
Теперь докажем обратное ,пусть известно,что $\lim\limits_{E\ni x\to a}f(x)=f(a)$,тогда идя по определению предела получим,что $$\forall V(f(a))\ \ \exists\mathring{U}_{E}(a) \ \ [ \ f(\mathring{U}_{E}(a))\subset V(f(a))\ ]$$
Но ведь $\mathring{U}_{E}(a)\subset U_{E}(a)$,учитывая это мы как раз и получим определение непрерывной функции в точке.
### Функция непрерывная в точке и предел перестановочны
То есть $$\lim\limits_{E\ni x\to a}f(x)=f(\lim\limits_{E\ni x\to a}x)$$
### Определение [[Предел по базе|предела по базе]] и непрерывной функции в точке эквиваленты
Если положить,что наша [[База фильтр|база]] $\mathcal{B}_{a}$ состоит из окрестностей $U(a)$ точки $a$,то как раз мы и получим определение предела по базе $$\lim\limits_{\mathcal{B}_a}f(x)=f(a)$$
### Существование предела по базе $\mathcal{B}_{a}$ окрестностей точки $a$ функции непрерывной в точке 
Если функция непрерывна в точке,значит предел по базе $\mathcal{B}_{a}$ окрестностей точки $a$ существует,это видно из предыдущего свойства
### Критерий непрерывность функции
Применим [[Критерий существования предела#Критерий Коши существования предела функции|критерий Коши]] и [[Непрерывная функция в точке#Существование предела по базе $ mathcal{B}_{a}$ окрестностей точки $a$ функции непрерывной в точке|факт о существовании предела и непрерывности функции]],получим,что функция $f:E\to\mathbb{R}$ непрерывна,тогда и только тогда,когда для любого $\varepsilon>0$ найдётся окрестность $U_{E}(a)$ на которой [[Колебание функции на множетсве|колебание]] $\omega(f;E)<\varepsilon$ меньше $\varepsilon$  
### Функция непрерывна в точке $a$ тогда и только тогда,когда её [[Колебание функции в точке|колебание в точке a]] $\omega(f;a)=0$ 
Докажем сначала обратное следствие.Пусть $\omega(f;a)=0$,тогда $\forall\varepsilon>0$ будет существовать окрестность $U^{\delta}_{E}(a)$ на которой $\omega(f;U^{\delta}_{E}(a))<\varepsilon$ ,тогда окрестности  $U^{\delta}_{E}(a)$ образуют базу $\mathcal{B}_{a}$ и мы выполнили [[Непрерывная функция в точке#Критерий непрерывность функции|критерий непрерывности функции]]
Теперь пусть функция $f$ непрерывна в точке $a$,тогда по [[Непрерывная функция в точке#Критерий непрерывность функции|критерию непрерывности функции]] получим,что $\forall\varepsilon>0$ cуществует $U^{\delta}_{E}\in\mathcal{B}_{a}$ такая ,что $\omega(f;U^{\delta}_{E}(a))<\varepsilon$,мы описали ,следующее определение предела $$\forall\varepsilon>0 \ \ \exists q >0 (\forall |\delta|<q \Rightarrow\ g(\delta)<\varepsilon \ \ )$$,только в нашем случае $g(\delta)=\omega(f;U^{\delta}_{E}(a))$ и а значит $\lim\limits_{\delta\to+0}g(\delta)=0$ ну или иначе $\omega(f;a)=0$ 

## Локальные свойства функции непрерывной в точке 
Пусть $f:E\to\mathbb{R}$ функция непрерывная в точке $a\in E$.Тогда справедливы следующие утверждения;
1) функция f [[Фу]]ограничена в некоторой окрестности $U_{E}(a)$
2) Если f ограничена в некоторой окрестности $U_{E}(a)$ точки a,то все значения f в этой окрестности принимают такой же знак как и $f(a)$
3) Если функция $g:U_{E}(a)\to\mathbb{R}$ определена в некоторой окрестности точки $a$ ,а так же непрерывна в точке a как и сама функция $f$,то:
	a) $(f+g)(x):=f(x)+g(x)$
	b) $(f\cdot g)(x) := f(x)\cdot g(x)$ 
	c) $(\frac{f}{g})(x) := \frac{f(x)}{g(x)}$,при условии ,что $g(x)\not=0$ 
	Определены в некоторой окрестности точки a и непрерывны в ней
4) Если функция $g:Y\to \mathbb{R}$ непрерывна в точке $b\to Y$,а функция $f:E\to Y$ непрерывна в точке $a\in E$ и $f(a)=b$,то композиция $(g\circ f)(x)$ непрерывна в точке a
### Доказательство 
1),2),3) Вспомним критерий для определения непрерывность функции в точки и получим,что из факт того функции $f$ и $g$ непрерывны следует,что существуют пределы $\lim\limits_{\mathcal{B}_a}f(x)$  $\lim\limits_{\mathcal{B}_a}g(x)$ ,а значит все эти утверждения можно доказать,как следствие соответствующих свойств предела по базе.
4)Следует из [[Критерий существования предела#Предел от Отображение Композиция отображений композиции функций|теоремы о пределе компазиции]] функций мы получим как раз искомое.
