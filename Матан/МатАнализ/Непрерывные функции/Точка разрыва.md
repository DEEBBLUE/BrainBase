# Определения
## Точка разрыва
Точкой разрыва функции $f:E\to\mathbb{R}$ называется та точка,в которой функция f не является непрерывной,формально это запишется так $$(a\in E - точка \ \ разрыва \ \ f) := \exists V(f(a))\ \ \forall U_{E}(a) \ \ \exists x\in U_{E}(a)(f(x\not\in V(f(a))))$$
Проверим это для [[Функция|функции]] $f(x)=sgn x$,в любой окрестности 0 [[Колебание функции в точке|колебание функции]] будет равным 2,а [[Непрерывная функция в точке#Функция непрерывна в точке $a$ тогда и только тогда,когда её Колебание функции в точке колебание в точке a $ omega(f;a)=0$|критерию непрерывность]] для непрерывных функций оно должно равняться 0,значит функция sgn x не непрерывна в 0.
## Устранимая точка разрыва
Если точка разрыва функции $f:E\to\mathbb{R}$ такова,что существует непрерывная функция $\tilde{f}:E\to\mathbb{R}$ такая ,что $\tilde{f}|_{E\verb|\|a}=f|_{E\verb|\|a}$ ,то точка a называется устранимой точкой разрыва функции $f:E\to\mathbb{R}$
## Точка разрыва первого рода 
Точка разрыва $a\in E$ называется точкой разрыва первого рода функции $f:E \to\mathbb{R}$, если существуют [[Предел по базе|пределы]] $$\lim\limits_{E\ni x\to a+0}f(x)=:f(a+0) \ \ \ и \ \ \ \lim\limits_{E\ni x\to a-0}f(x)=:f(a-0)$$
Но по крайней мере 1 предел не совпадает со значением функции f в точке a
## Точка разрыва второго рода
Если $a$ точка разрыва функции $f:E\to\mathbb{R}$,такая что хотя бы 1 предел по [[База фильтр|базе]] $\mathcal{B}_{a^+}$ или $\mathcal{B}_{a^-}$ не существует,то точка $a$ называется точкой разрыва второго рода.
# Теоремы
## Следствие определения устранимой точки 
Можно положить ,при условии ,что существует предел $\lim\limits_{x\to a}f(x)=A$ ,как $$\tilde{f}=\left\{ \begin{aligned} f(x), \quad x \not= a \\ A, \quad x = a \end{aligned} \right.$$
Но необязательно,что если предела $\lim\limits_{x\to a}f(x)$ не существует,то нельзя будет построить $\tilde{f}$
