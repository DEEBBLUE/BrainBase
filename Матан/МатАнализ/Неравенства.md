## Неравенство Юнга 
Прежде чем перейти к неравенству Юнга,докажем другое неравенство 
### Неравенство 
При $x>0$ $$x^{\alpha}-\alpha x+\alpha-1\le 0,\ \ когда \ \ 0<\alpha<1$$
$$x^{\alpha}-\alpha x+\alpha-1\geq 0,\ \ когда \ \ \alpha<0 \ \ или \ \ 1<\alpha$$
#### Доказательство 
Найдём [[Дифференциальное исчисление функции одной переменной|производную]] от [[Функция|функции]] $f(x)=x^{\alpha}-\alpha x+\alpha-1$ - $f'(x)=\alpha(x^{\alpha-1}-1)$.Рассмотрим значение производная в точке 1,очевидно $f'(1)=0$,значит по [[Дифференциальное исчисление функции одной переменной#Лемма Ферма|по лемме Ферма]] точка $x=1$ - является [[Функция#Точка внутреннего экстремума|точкой внутреннего экстремума]] ,тогда если $0<\alpha<1$,то если $0<x<1$ производная будет положительной ,а если $1<x$,то уже отрицательной,значит в этом случае $x=1$ - это [[Функция#Точка локального максимума(минимума)| точка строго локального максимума]].Кроме этого,значение функции $f(1)=0$ ,а значит ,что если $0<\alpha<1$ и $x\not= 1$ ,то значение функции будет строго меньше 0.Аналогично можно доказать,и для случая $\alpha<0 \ \ или \ \ 1<\alpha$ 
Теперь само неравенство Юнга
Если $a>0 \ \ и \ \ b>0$,а числа $p,q$ таковы,что $p\not=0,1, \ q\not=0,1$ и $\frac{1}{p}+\frac{1}{q}=1$,то $$a^{1/p}b^{1/q}\le\frac{1}{p}a+\frac{1}{q}b,если \ \ p>1,$$
$$a^{1/p}b^{1/q}\geq\frac{1}{p}a+\frac{1}{q}b,если \ \ p<1,$$
Достаточно в доказанном выше неравенстве положить,что $x=\frac{a}{b}$ и $\alpha=\frac{1}{p}$ ,а так же внести обозначение $\frac{1}{q}=1-\frac{1}{p}$

## Неравенство Гёльдера
Пусть $x_i\geq0$ и  $y_i\geq0$ ($i=1,2,3...,n$) и $\frac{1}{p}+\frac{1}{q}=1$.Тогда $$\sum\limits_{i=1}^{n}x_iy_i\le(\sum\limits_{i=1}^{n}x_i)^{1/p}(\sum\limits_{i=1}^{n}y_i)^{1/q} \ \ \ \ \ при \ \ p>1$$
$$\sum\limits_{i=1}^{n}x_iy_i\geq(\sum\limits_{i=1}^{n}x_i)^{1/p}(\sum\limits_{i=1}^{n}y_i)^{1/q} \ \ \ \ \ при \ \ p<1,p\not=0$$
### Доказательство 
Пусть $X=\sum\limits_{i=1}^{n}x_i^p>0$ и  $Y=\sum\limits_{i=1}^{n}y_i^q>0$.Положим,что $a=\frac{x_i^p}{X}$ и $b=\frac{y_i^q}{Y}$,тогда по неравенству Юнга,получим,что $$\frac{x_iy_i}{X^{1/p}Y^{1/q}}\le\frac{1}{p}\frac{x_i^{p}}{X}+\frac{1}{q}\frac{y_i^q}{Y}$$
Теперь просуммируем эти неравенства по i от 1 до n.Тогда $$\sum\limits^{n}_{i=1}\frac{x_iy_i}{X^{1/p}Y^{1/q}}\le\sum\limits_{i=1}^{n}(\frac{1}{p}\frac{x_i^p}{X}+\frac{1}{q}\frac{y^{q}_{i}}{Y})$$$$\frac{1}{X^{1/p}Y^{1/q}}\sum\limits_{i=1}^{n}x_iy_i\le\frac{1}{pX}\sum\limits_{i=1}^{n}x_i^p+\frac{1}{qY}\sum\limits_{i=1}^{n}y_i^q=\frac{1}{pX}X+\frac{1}{qY}Y=\frac{1}{p}+\frac{1}{q}=1$$
То есть $$\frac{\sum\limits_{i=1}^{n}x_iy_i}{X^{1/p}Y^{1/q}}\le 1$$
Или $$\sum\limits_{i=1}^{n}x_iy_i\le X^{1/p}Y^{1/q}=(\sum\limits_{i=1}^{n}x_i)^{1/p}(\sum\limits_{i=1}^{n}y_i)^{1/q}$$
Ч.т.д.
## Неравенство Минковского 
Пусть $x_i\geq 0$ ,$y\geq 0$ ($i=1,...,n$).Тогда $$(\sum\limits_{i=1}^{n}(x_i+y_i)^p)^{1/p}\le(\sum\limits_{i=1}^{n}x_i^p)^{1/p}+(\sum\limits_{i=1}^{n}y^p)^{1/p}, \ \ при \ \ p>1$$
$$(\sum\limits_{i=1}^{n}(x_i+y_i)^p)^{1/p}\geq(\sum\limits_{i=1}^{n}x_i^p)^{1/p}+(\sum\limits_{i=1}^{n}y^p)^{1/p}, \ \ при \ \ p<1$$
### Доказательство 
Сначала представим левую часть в виде $$\sum\limits_{i=1}^{n}(x_i+y_i)^p=\sum\limits_{i=1}^{n}x_i(x_i+y_i)^{p-1}+\sum\limits_{i=1}^{n}y_i(x_i+y_i)^{p-1}$$
Пусть $p>1$.Тогда применяя к ней неравенство Гёльдера получим следующее выражением: $$\sum\limits_{i=1}^{n}(x_i+y_i)^p\le(\sum\limits_{i=1}^{n}x_i^p)^{1/p}(\sum\limits_{i=1}^n((x_i+y_i)^{p-1})^{q})^{1/q}+(\sum\limits_{i=1}^{n}y_i^p)^{1/p}(\sum\limits_{i=1}^n((x_i+y_i)^{p-1})^{q})^{1/q}$$
Или,если учесть ,что $\frac{1}{p}+\frac{1}{q}=1\rightarrow q=\frac{p}{p-1}$ и заметить, что $(p-1)q=(p-1)\frac{p}{p-1}=p$ .Тогда $$\sum\limits_{i=1}^{n}(x_i+y_i)^p\le(\sum\limits_{i=1}^{n}x_i^p)^{1/p}(\sum\limits_{i=1}^n(x_i+y_i)^{p})^{1/q}+(\sum\limits_{i=1}^{n}y_i^p)^{1/p}(\sum\limits_{i=1}^n(x_i+y_i)^{p})^{1/q}$$
Теперь вынесем общий множитель и получим,что $$\sum\limits_{i=1}^{n}(x_i+y_i)^p\le[(\sum\limits_{i=1}^{n}x_i^p)^{1/p}+(\sum\limits_{i=1}^{n}y_i^p)^{1/p}](\sum\limits_{i=1}^n(x_i+y_i)^{p})^{(p-1/p)}$$
Теперь разделим на $(\sum\limits_{i=1}^n(x_i+y_i)^{p})^{(p-1/p)}$ обе части и получим,что $$\frac{\sum\limits_{i=1}^{n}(x_i+y_i)^p}{(\sum\limits_{i=1}^n(x_i+y_i)^{p})^{(p-1/p)}}=\frac{\sum\limits_{i=1}^{n}(x_i+y_i)^p}{\sum\limits_{i=1}^{n}(x_i+y_i)^p\cdot(\sum\limits_{i=1}^{n}(x_i+y_i)^p)^{-\frac{1}{p}}}=(\sum\limits_{i=1}^n(x_i+y_i)^p)^{1/p}\le (\sum\limits_{i=1}^{n}x_i^p)^{1/p}+(\sum\limits_{i=1}^{n}y_i^p)^{1/p}$$
Ч.т.д.
Для случая $p<1$ тоже самое,только знак неравенства противоположный
