## Неравенство Юнга 
Прежде чем перейти к неравенству Юнга,докажем другое неравенство 
### Неравенство 
При $x>0$ $$x^{\alpha}-\alpha x+\alpha-1\le 0,\ \ когда \ \ 0<\alpha<1$$
$$x^{\alpha}-\alpha x+\alpha-1\geq 0,\ \ когда \ \ \alpha<0 \ \ или \ \ 1<\alpha$$
#### Доказательство 
Найдём [[Дифференциальное исчисление функции одной переменной|производную]] от [[Функция|функции]] $f(x)=x^{\alpha}-\alpha x+\alpha-1$ - $f'(x)=\alpha(x^{\alpha-1}-1)$.Рассмотрим значение производная в точке 1,очевидно $f'(1)=0$,значит по [[Дифференциальное исчисление функции одной переменной#Лемма Ферма|по лемме Ферма]] точка $x=1$ - является [[Функция#Точка внутреннего экстремума|точкой внутреннего экстремума]] ,тогда если $0<\alpha<1$,то если $0<x<1$ производная будет положительной ,а если $1<x$,то уже отрицательной,значит в этом случае $x=1$ - это [[Функция#Точка локального максимума(минимума)| точка строго локального максимума]].Кроме этого,значение функции $f(1)=0$ ,а значит ,что если $0<\alpha<1$ и $x\not= 1$ ,то значение функции будет строго меньше 0.Аналогично можно доказать,и для случая $\alpha<0 \ \ или \ \ 1<\alpha$ 
Теперь само неравенство Юнга
Если $a>0 \ \ и \ \ b>0$,а числа $p,q$ таковы,что $p\not=0,1, \ q\not=0,1$ и $\frac{1}{p}+\frac{1}{q}=1$,то $$a^{1/p}b^{1/q}\le\frac{1}{p}a+\frac{1}{q}b,если \ \ p>1,$$
$$a^{1/p}b^{1/q}\geq\frac{1}{p}a+\frac{1}{q}b,если \ \ p<1,$$
Достаточно в доказанном выше неравенстве положить,что $x=\frac{a}{b}$ и $\alpha=\frac{1}{p}$ ,а так же внести обозначение $\frac{1}{q}=1-\frac{1}{p}$
