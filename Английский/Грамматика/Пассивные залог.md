Построение [[Времена|времён]] которые я описал выполняются только при активном залоге
Активный залог это когда лицо о котором говорится в предложение само совершает действия,например: I was looking for a treasure in the past (я искал клад в прошлом)
В пассивном же залоге действие совершается над подлежащим.Кроме этого пассивный залог отличается по построению.Единственное что их всех объединяет,так это общее правило построения вопросительных и отрицательных предложений.При построении вопросительного предложения первое слово в глагольной форме уходит вперёд,точно так же и в отрицательных предложениях частица not пишет после первого слова в глагольной форме
# Simple Passive
Пассивный залог всех времён simple строится по следующему шаблону $$Подл. \ \ + \ \ to \ \ be \ \ + \ \ V_3 $$
To be меняется в зависимости от времени
## Past Simple Passive
$$Подл. \ \ + \ \ was/were \ \ + \ \ V_3 $$
## Present Simple Passive
$$Подл. \ \ + \ \ am/are/is \ \ + \ \ V_3 $$
## Future Simple Passive 
$$Подл. \ \ + \ \ will \ \ be \ \ + \ \ V_3 $$
# Continuous Passive
$$Подл. \ \ + \ \ to \ \ be \ \ + \ \ being \ \ + \ \ V_3 $$
Изменяется только глагол to be по временам ,как в Simple 
# Progressive Passive 
$$Подл. \ \ + \ \ have/has \ \ +\ \ been \ \ + \ \ V_3 $$
В Past Progressive Passive have заменяется на had.В Future Progressive Passive на will have
